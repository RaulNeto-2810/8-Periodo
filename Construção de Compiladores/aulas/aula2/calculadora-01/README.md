## 📌 Exemplos de Testes

### 🔹 Operações Aritméticas

| Entrada  | Saída |
|----------|-------|
| `2+3`    | `= 5` |
| `10-4`   | `= 6` |
| `7*8`    | `= 56` |
| `10/2`   | `= 5` |
| `7\3`    | `= 2` |
| `7%3`    | `= 1` |
| `2^4`    | `= 16` |
| `5!`     | `= 120` |
| `[-15]`  | `= 15` |
| `-7+3`   | `= -4` |
| `(2+3)*4` | `= 20` |
